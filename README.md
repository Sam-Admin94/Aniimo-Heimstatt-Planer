# Aniimo-Heimstatt-Planer 🇩🇪

Deutsche Neugestaltung des Open-Source-Heimstatt-Optimierers [Aniimax](https://github.com/ae-bii/aniimax).

## Projektstatus
Repository angelegt. Der vollständige Projektcode muss noch importiert, die Übersetzung abgeschlossen und die WebAssembly-Optimierung erfolgreich gebaut und getestet werden. **Noch keine einsatzfähige Website.**

## Projektdateien
Der vorbereitete Quellcode liegt als `Heimstatt-Planer-DE-GitHub-Build.zip` vor. Nach dem Import ins Repository kann der Workflow `.github/workflows/deploy-de.yml` den Build auf GitHub Actions ausführen.

## Lizenz
Die ursprünglichen Urheber- und Lizenzhinweise des Aniimax-Projekts sind beim Import beizubehalten.
